---
severity: error
scope: core
title: an `optional` (nullable) field is used in `order_by`, and it isn't the list's range.
---

Keyset pagination compares sort values, and comparisons with NULL are
unknown, so rows with a NULL sort value would silently drop out of the pages.
A range filter excludes NULLs explicitly, so a nullable field is fine as the
range.

Fix: make the field required (with a default, if the table exists already),
or make it the range.
