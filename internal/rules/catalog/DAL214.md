---
severity: error
scope: pg
title: a table needs a sqlc rename, and a column has the same name as the table.
---

When a table's name differs from its message name (`orders` for `Order`),
dalforge tells sqlc to name the model after the message. sqlc applies that
rename to columns too, so a column called `orders` would be renamed as well.
Fix: rename the column or the table.
