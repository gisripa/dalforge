---
severity: error
scope: core
title: the request or response message doesn't match the access pattern.
---

The messages must contain exactly the fields the pattern uses, with the same
types as the entity's fields:

| Pattern | Request | Response |
|---|---|---|
| get | the entity, or exactly the `by` fields | the entity |
| list | exactly the `eq` fields, `<range>_from`/`<range>_to`, `int32 page_size`, `string page_token` | one `repeated` entity field and `string next_page_token` |
| create, update, upsert | the entity | the entity |
| delete | the entity, or exactly the key fields | the entity, or `google.protobuf.Empty` |

The message names the missing, unexpected or mistyped fields.
