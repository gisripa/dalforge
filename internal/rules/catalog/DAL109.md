---
severity: warning
scope: core
title: a list sorts by a field that an update or upsert can change.
---

If a row's sort value changes while a client pages through the list, the row
can move to a page the client has already read (it's missed) or to one it
hasn't read yet (it shows up twice).

Fix: sort by something stable (the creation time, the key), or accept it for
lists where this doesn't matter.
