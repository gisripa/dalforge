---
severity: error
scope: core
title: a list's `range` must be its leading `order_by` field.
---

An index can return rows in order of a column while ranging over that same
column, but it can't range over one column while sorting by another.

```proto
list: {eq: ["status"] range: "created_at" order_by: ["priority DESC"]}   // DAL101
list: {eq: ["status"] range: "created_at"}                               // sorted by created_at
```

Fix: drop the `order_by` (the range field becomes the sort), or start it with
the range field.
